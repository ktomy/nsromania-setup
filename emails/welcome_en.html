You can also view glucose readings on your phone using these apps:

  • Android
    • Nightwatch
      • In the menu/settings, select “Read from Nightscout”.
      • Then enter the website address shown in the technical details below in the next menu.
    • Xdrip+
      • Menu → Settings → Hardware Data Source → Nightscout Follower
      • A new menu will appear below “Hardware Data Source”. Enter the website address from the technical details below in that menu.
  • iPhone
      On iOS, you can use Nightguard. Enter the website address in Preferences.

On your child’s phone, if you use xDrip as the data source:

  • Open xDrip, tap the menu (top left), then Settings → Cloud Upload (the cloud with an upward arrow) → Nightscout Sync. In “Base URL”, enter: https://{{api_secret}}@{{subdomain}}.nsromania.info/api/v1/
